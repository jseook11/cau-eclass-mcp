# PDF 시험 시간표 파서 코드 리뷰 — 2026-10-07

후속 수정 상태: 아래 리뷰에서 확인한 다섯 오류를 수정했다. 변경과 검증 범위는 [수정 기록](pdf-parser-fix-2026-10-07.md)을 참고한다. 아래 본문은 수정 전 리뷰 결과다.

대상: HEAD `7ba2fe2` 위의 미커밋 `src/tools/exams/pdf-parser.ts` 변경과 호출 경로. 서비스 소스는 수정하지 않았다. 기존 PDF 세 개를 로컬에서 재파싱하고, 경영경제 PDF 첫 페이지 렌더링·TSV와 결과를 비교했다. 재현은 빌드한 모듈의 공개 함수 `parseExamScheduleTsv`를 사용했다. 네트워크 동기화나 운영 DB 쓰기는 수행하지 않았다.

검증: `pnpm run build`, `pnpm test` **446/446**, `git diff --check` 통과. 기존 시험 테스트는 35/35 통과한다. 새 파서에 추가된 테스트는 헤더 없는 범용 행의 정상 사례 한 개이며, 아래 오류를 검증하지 않는다.

## 1. [P1] 헤더 시작점의 중간값은 실제 열 경계가 아니다

위치: `src/tools/exams/pdf-parser.ts:453-458`, `502-510`.

헤더가 셀 가운데 정렬되고 본문이 왼쪽 정렬된 표에서, 이웃 헤더의 시작 x좌표 중간값으로 경계를 만들면 본문 앞부분이 이전 열에 들어간다. 이어서 이름 셀이 비면 가장 긴 문자열을 과목명으로 선택해 오류를 확대한다.

실제 파일 `~/Downloads/eclass-exams/2026-1/final/2026-1학기 기말시험 시험유형 및 시간표_공지_최종_v2.pdf`는 428행을 반환하지만 다음 필드가 틀린다. 첫 페이지 원문과 렌더링에서 확인했다.

| 학수번호 | 원문 과목명 | 반환 course_name |
| --- | --- | --- |
| 54288 | 벤처창업 경영론 | 경영론 |
| 54262 | 암호와 인증 | 인증 |
| 58718 | 안전한인공지능 | 3 310관 721호 <강의실> |
| 40150 | 파생상품 | 3 310관 721호 <강의실> |

58718의 교수명도 `김호기` 대신 `/ 목(16:30~17:45) 김호기`로 반환된다. 이런 값은 `syncExamSchedules`의 `cache.replaceSchedules`로 정상 데이터처럼 저장된다.

보강: 본문 열 시작점의 분포와 헤더 영역을 함께 사용해 경계를 추정한다. 신뢰할 수 없는 이름은 강의실·다른 열로 채우지 말고 미해석 상태와 원문 근거를 남긴다. 이 실제 문서의 과목명·교수명까지 검증하는 회귀 fixture가 필요하다.

## 2. [P1] 비대면을 대면으로 정규화한다

위치: `src/tools/exams/pdf-parser.ts:386-389`.

`/대면/` 검사를 먼저 하므로 `온라인(비대면)시험`의 `비대면`도 매칭된다. 헤더 없는 범용 입력 `54288 | 01 | 온라인수업 | 온라인(비대면)시험 | 2026-06-19`를 넣으면 `exam_method: 대면시험`으로 반환된다. 기존 온라인 시험 테스트는 전용 파서 경로만 검증해 통과한다.

보강: 온라인·비대면을 먼저 판별하거나 정확한 표준 문자열로 정규화한다. 범용 경로의 온라인 표기 변형을 검증한다.

## 3. [P1] 격자형 파서가 날짜당 한 행으로 모든 교시를 합친다

위치: `src/tools/exams/pdf-parser.ts:649-685`.

주석은 셀당 한 레코드를 약속하지만 실제 코드는 날짜 marker를 순회해 전체 가로 band를 한 문자열로 합친다. `gridTimeRanges`가 구한 x좌표는 사용하지 않으며, 시간 헤더는 제외하고 본문에서 첫 시간만 찾는다.

재현: 1~6교시 헤더, 09:00~10:00부터 시작하는 시간 헤더, 같은 날짜 `6/19`의 1교시 `과목A`, 2교시 `과목B`를 넣으면 한 행 `course_name: 과목A 과목B`, 시작·종료 `null`이 반환된다. 시험방법은 근거 없이 대면으로 고정된다.

보강: 페이지별 교시 x구간과 날짜 y구간의 교차 셀로 분리하고 각 셀에 해당 교시 시간을 연결한다. 표에 시험방법이 없으면 null 또는 별도 후보 상태로 보존한다.

## 4. [P2] 날짜를 학기로 오인하여 겨울학기 행을 삭제한다

위치: `src/tools/exams/pdf-parser.ts:355`, `595-598`.

`GENERIC_TERM`은 행 전체에서 `2026-1-14`의 `2026-1`도 학기로 인식한다. `term=2025-W`의 정상 겨울 시험 행 `54288 | 01 | 계절과목 | 대면시험 | 2026-1-14`를 넣으면 행이 제거돼 `EXAM_PARSER_UNSUPPORTED`가 반환된다. 기존 계절학기 fixture는 이 범용 날짜 처리 경로를 검증하지 않는다.

보강: 학기 전용 열에서만 값을 읽거나, 날짜 패턴과 겹치지 않는 학기 구문을 사용한다. 1~2월 비패딩 날짜 회귀 검증이 필요하다.

## 5. [P2] 안내문 날짜·시간을 시험 일정으로 확정한다

위치: `src/tools/exams/pdf-parser.ts:527`, `576-585`.

과목 식별자가 없어도 날짜나 시간 하나만 있으면 행을 허용한다. `시험 안내 / 제출기한 2026-06-19 18:00`만 있는 입력도 `ok: true`, `course_name: 시험 안내 제출기한`, 시험 날짜와 시작 시각으로 반환된다. 서약서·제출 안내가 섞인 PDF에서는 실제 일정처럼 캐시에 들어갈 수 있다.

보강: 정규 일정 저장에는 과목 행이라는 구조적 근거가 필요하다. 안내문·미식별 내용은 원문 덤프에 보존하되 일정 후보와 확정 결과를 구분한다. 추측한 필드를 파싱 성공만으로 확정하지 않는다.

## 남아 있는 하드코딩과 설계 보강

- 전용 파서의 고정 열 배열은 183~187, 230~241, 264~268, 318~322행에 남아 있다. 기존 형식 호환용으로 둘 수 있지만 인쇄 배율·열 순서 변화의 기준 경로로 사용하기에는 취약하다.
- 범용 파서도 간격 4, 헤더 군집 폭 22, 헤더 y거리 80, 코드 열 폭 120, 격자 감지 최소 6교시, 날짜 가장자리 여유 -90/+60에 의존한다. 문서·글꼴 크기에 비례한 기준과 관측한 열 간격을 우선한다.
- `detectHeaderBounds`는 페이지를 구분하지 않고 비슷한 y좌표의 헤더를 합친다. 페이지마다 열 위치나 표가 다른 PDF에서는 헤더를 페이지/표 단위로 추정해야 한다. 이 항목은 정적 코드에서 확인했으며 별도 실제 다중 레이아웃 PDF로 재현하지 않았다.
- 파서 선택은 교수명이 전용 경로에 없고 범용 경로에 절반 이상 있다는 기준이다(774~781행). 행 커버리지와 이름·날짜·시각·장소의 타당성을 함께 비교해야 한다. 교수명 존재 자체는 정확성의 증거가 아니다.
- `raw_text`는 식별된 행에만 존재하며 문서 전체·페이지 근거·제외된 텍스트를 반환하지 않는다. 자료 확보, 원문 추출, 해석 결과를 구분하고 미해석 자료도 읽을 수 있는 경로를 제공하는 것이 양식 배열 추가보다 우선이다.
