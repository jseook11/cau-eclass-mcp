# PDF 파서 리뷰 수정 — 2026-10-07

대상은 같은 날 리뷰에서 확인한 다섯 오류와 직접 관련된 범용 파서 경로다. 기존 다른 에이전트의 미커밋 변경 위에서 수정했으며, 오류 응답·다운로드 등 다른 기능의 변경은 이번 작업에 포함하지 않았다.

## 변경

- 비대면·온라인 표기를 대면보다 먼저 인식한다. `온라인시험`, `비대면시험`, `온라인(비대면)시험`을 지원한다.
- 학기는 행 선두의 선언에서만 읽고 날짜의 일부를 학기로 인식하지 않는다. `2025-W`의 `2026-1-14` 시험을 보존한다.
- 날짜나 시각만 있는 안내문을 일정으로 저장하지 않는다. 과목 코드 또는 헤더로 확인된 과목명·분반이 필요하다.
- 헤더 경계는 본문에서 반복되는 열 시작 위치와 빈 간격으로 추론한다. 숫자 오른쪽 정렬도 고려한다. 새 문서에 맞춘 고정 x좌표 배열은 추가하지 않았다.
- 헤더는 페이지별로 감지하고, 후속 페이지에 헤더가 생략된 경우 직전 헤더를 재사용한다. 명시적인 이름 열이 비어 있으면 다른 열의 가장 긴 문자열로 채우지 않는다.
- 시험 시각 열이 존재하지만 비어 있으면 강의시간에서 시각을 가져오지 않는다. `.` 또는 `-` 등 빈 셀 표시는 null로 처리한다.
- 격자는 날짜와 교시의 교차 셀마다 레코드를 만들고 교시 헤더의 시간을 연결한다. 기존 최소 6교시 가정은 제거했다. 근거 없는 대면시험 고정값도 제거했다. 괄호가 있는 과목명과 셀별 시험 장소를 보존한다.

## 회귀 검증

`test/exam-pdf-generic.test.ts`에 9개 테스트를 추가했다. 최초 오류를 재현한 6개는 수정 전 모두 실패했다. 추가로 인쇄 배율·이동, 빈 시험 시각, 날짜·페이지·빈 격자 셀을 검증한다.

실제 자료 fixture `test/fixtures/exam-bne-generic-final-2026-1.tsv`는 Downloads에 있던 경영경제 2026-1 기말 최종 v2 PDF에서 추출한 첫 페이지 헤더·첫 12행 및 헤더 없는 두 번째 페이지 첫 4행이다. 원래 단어 좌표와 폭을 보존했다. 테스트는 과목명·교수명·강의시간·시작/종료 시각·건물·고사실 및 온라인 시험 필드를 검증한다. 인쇄 배율 검증에서는 타이포그래피에 따라 달라지는 공백을 제외하고 필드의 문자 내용과 숫자를 비교한다.

검증 결과:

- TypeScript 빌드 통과.
- 전체 테스트 **455/455**, 실패·skip 없음.
- `git diff --check` 통과.
- 실제 로컬 PDF 재파싱: 교양 664행, 경영경제 428행, 소프트웨어 98행.
- 경영경제 전체 428행의 과목명·교수명을 TSV 본문 열과 별도로 대조해 공백을 제외한 문자 내용이 모두 일치함을 확인했다. 시각·건물·고사실도 대조했으며, 다른 열의 문장이 넘쳐 들어온 일부 셀은 정규 시각 패턴을 직접 확인했다. 이 검증은 좌표 기반 대조이며 모든 페이지의 모든 셀을 시각적으로 검수한 것은 아니다.
- 실제 PDF 실행은 로컬 파싱만 수행했다. 운영 시험 DB 재동기화, 커밋·푸시는 수행하지 않았다.

## 남은 범위

기존 양식 호환용 전용 파서의 고정 좌표 배열은 남아 있다. 범용 열 추론에도 휴리스틱이 있으며, 새로운 양식 전체의 정확성을 보장하지 않는다. 격자 회귀는 합성 TSV로 검증했으며 실제 격자형 PDF 표본은 이번 작업에 없었다. 문서 전체 원문 조회 API, 파싱 신뢰도/미해석 상태를 포함한 출력 계약 개편은 별도 작업이다.
